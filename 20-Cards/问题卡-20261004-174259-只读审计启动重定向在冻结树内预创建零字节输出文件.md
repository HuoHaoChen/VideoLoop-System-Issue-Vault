# 🟢 只读审计启动重定向在冻结树内预创建零字节输出文件

==待处理== · 待分类 · <kbd>未设</kbd>

---

> [!question]+ 结论
> 只读审计进程开始前，调用包装层已在被审计冻结树内创建两个零字节输出文件，导致审计自身破坏只读边界；文件创建发生在冻结时间之后，且在审计方首个盘面快照之前。

---

> [!quote] 发生了什么

**事实链：**

```
FREEZE frozen_at = 2026-10-04T17:08:45
95-NARROW-CORRECTION/50-AUDIT/HERMES_AUDIT_RAW_PATCH1C.txt birthtime = 2026-10-04T17:11:32, bytes = 0
95-NARROW-CORRECTION/50-AUDIT/HERMES_AUDIT_ERR_PATCH1C.txt birthtime = 2026-10-04T17:11:32, bytes = 0
审计简报要求：只读，不得修改、创建、删除任何仓库内文件；真实 FROZEN 树逐字节不变。
审计方首个全树快照之后至测试完成，全树 531 项 aggregate sha256 保持 f46609d54cfc943b94ddd03eecf6f348d79ee2b3b71abace734645f4d1fad939。
```

---

| 判断 | 依据 |
|:-----|:-----|
| ==真实只读完整性故障== | 两个审计输出文件位于真实冻结树内，且 birthtime 晚于 freeze；即使内容为空，创建目录项本身已改变冻结树。 |
| ==疑似启动命令重定向副作用== | 文件名分别对应 stdout/stderr，且同秒创建、均为 0 字节；需由第二裁判或人工检查 DSH 启动命令确认根因。 |
