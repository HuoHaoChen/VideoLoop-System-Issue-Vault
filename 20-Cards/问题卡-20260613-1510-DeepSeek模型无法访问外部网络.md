# 🟢 DeepSeek 上不了网

==已解决== · 系统域 · <kbd>6/13</kbd>

---

> [!success]+ 结论
> 根因：`base_url` 末尾多了一个 <span style="color:#ef4444;font-weight:bold">/v1</span>
> 
> 改前：`https://api.deepseek.com/v1` → 拼成 `/v1/v1` → 404
> 
> 改后：`https://api.deepseek.com` → <span style="color:#22c55e">浏览器正常访问外网 ✅</span>

---

> [!quote] 发生了什么

**事实链：**

```
Hermes 开启 web 搜索工具 ✅
        ↓
DeepSeek 模型说「上不了网」❌
        ↓
查 config → base_url 多了 /v1
        ↓
去掉 /v1 → 浏览器立刻能抓 HackerNews 头条
```

---

| 判断 | 依据 |
|:-----|:-----|
| ==不是工具没开== | `hermes tools list` 确认 web ✅ browser ✅ |
| ==base_url 是根因== | 改动后当场验证通过 |
| ==不是 API key 问题== | 模型能正常对话，只是工具调用路径错了 |
