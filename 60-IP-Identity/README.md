# 60-IP-Identity｜IP 实体层

> 回答「这个内容判断为什么是我会做出的判断」。

## 三类实体

| 实体 | 前缀 | 回答什么问题 |
|------|------|-------------|
| Persona 人格卡 | PER- | 你是谁 — 你怎么出现在内容里 |
| Values 价值观卡 | VAL- | 你信什么 — 什么让你做出取舍 |
| Worldview 世界观卡 | WV- | 你怎么看世界 — 你用什么框架解释现象 |

## 使用规则

1. **生成内容前先扫 IP 层**：确保输出符合你的风格指纹
2. **冲突时建 Meta 卡记录**：如果内容与 IP 层冲突，记录为什么
3. **不做硬编码引用列表**：Dataview 反向查询自动显示关联卡片

## 风格指纹

```
现实行为拆解型内容风格：
从用户行为反推真实困境
→ 用反常识判断解释误判
→ 最后给一个可执行修正动作
```
