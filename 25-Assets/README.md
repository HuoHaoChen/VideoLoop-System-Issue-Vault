# 25-Assets｜内容判断资产沉淀

> 这里是校准后的判断资产索引层，不是替代 20-Cards。

```
20-Cards = 校准过程（活跃判断循环）
25-Assets = 资产沉淀（校准后形成的可复用资产）
```

## 存入什么

| 资产类型 | asset_type | 说明 |
|----------|-----------|------|
| 用户困境判断 | `user_pain_hypothesis` | 已验证或正在验证的用户真实困境 |
| 反常识判断 | `counterintuitive_judgment` | 反常识但被现实支持的内容判断 |
| 成功条件 | `success_condition` | 已验证有效的结构/Hook/表达方式 |
| 失败反模式 | `failure_antipattern` | 已验证的失败模式与规避规则 |
| 边界条件 | `boundary_condition` | 方法的适用/失效边界 |

## 准入规则

- 优先收录 S2/S3 资产
- S1 可录入但标注「单样本，待复测」
- S0 不入
- 每条必须有来源卡片引用
- 格式使用卡片模板
