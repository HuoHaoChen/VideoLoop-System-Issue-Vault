# 00-Inbox — 四工具投递入口

任何工具遇到问题/完成解决记录，把「快速投递」文件放这里（模板见 `90-Templates/TEMPLATE-快速投递.md`），然后：

```bash
python3 scripts/ingest.py            # 入库：KEDB 查重 → 建 P 卡 → 归档
python3 scripts/ingest.py --dry-run  # 先演练，不落盘
```

规则：

- 文件名随意，`*.md` 即可；处理完自动移入 `processed/`。
- KEDB 命中 = 复发：自动 repeat_count+1 并挂 ke_ref，不重复建卡。
- 新条目不自动进 KEDB：人工确认是「已知顽疾」后再登记 known_error_db.json（防 AI 自报污染）。
