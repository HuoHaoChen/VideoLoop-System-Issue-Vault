# VideoLoop — 给人类的说明

## 这是什么

VideoLoop 是一套帮你「不自欺」的决策追踪系统。你做短视频内容，每做一个判断（选题对不对、表达好不好、系统怎么改进），这里记一笔。月末回头看：哪些判断准了，哪些是自我安慰。

它不是笔记软件，不是灵感仓库（灵感记在别处）。它只做一件事：**把你的决策过程变成可审计的数据**。

## 四张核心卡片（加上三张 IP 卡片）

| 卡 | 什么时候建 | 一句话 |
|:---|:---|:---|
| **问题卡 (P)** | 你发现哪里不对了 |「前3秒留不住人」 |
| **修改卡 (C)** | 你决定怎么改 |「把Hook从15秒缩到3秒」 |
| **校准卡 (CAL)** | 你定义「什么叫有效」 |「前3秒完播率>60%才算留住了」 |
| **元卡 (M)** | 每月复盘 |「这个月发现的3条新原则」 |
| **人格卡 (PER)** | 你定义你是谁 |「认知翻译官：把复杂机制翻译成操作结论」 |
| **价值观卡 (VAL)** | 你定义你信什么 |「尊重长期主义：不做三月后没用的内容」 |
| **世界观卡 (WV)** | 你定义你怎么看世界 |「万物两面性：问题的反面就是答案」 |

## 一条灵感怎么走到一条视频

```
灵感/问题  →  问题卡(P)  →  修改卡(C)  →  校准卡(CAL)
                                          ↕
                                    世界观卡(WV)
                                    价值观卡(VAL)
                                          ↕
                                  40-Projects/ 脚本
                                          ↓
                                      视频/文案
```

## 怎么用（最简单的路径）

```bash
cd ~/Desktop/VideoLoop

# 1. 发现问题 → 建问题卡
python3 scripts/new_card.py problem "我的标题"

# 2. 打开文件，填内容

# 3. 设计方案 → 建修改卡
python3 scripts/new_card.py change "我的方案"

# 4. 打开文件，填内容，关联问题卡和校准卡

# 5. 检查有没有遗漏
python3 scripts/validate_loop.py .
```

## 两个最重要的看板

- **待办与逾期** (`30-Dashboards/待办与逾期.md`) — 哪些卡该处理了
- **引用统计** (`30-Dashboards/引用统计看板.md`) — 哪些校准卡被真正用上了

## 三个铁律

1. **单一真相源** — 这个仓库里的结论是权威版本，不在聊天记录里记决策
2. **先校准后下结论** — 没引用校准卡的修改卡不能判「有效」
3. **记录的人和评判的人不能是同一个人** — 自己不能裁判自己
