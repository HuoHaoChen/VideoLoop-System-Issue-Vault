# 💡 灵感看板

> ⚠️ 当前 20-Cards/ 中尚无 inspiration 卡片，看板暂时为空，
> 这是预期状态，等首张灵感卡建成后自动填充。

## 待加工灵感（按优先级）

```dataview
TABLE 
  raw AS "原始闪念", 
  domain AS "归域", 
  status AS "状态", 
  priority AS "优先级",
  review_date AS "复评日期"
FROM "20-Cards"
WHERE type = "inspiration" AND status != "降级归档" AND status != "已出库"
SORT priority DESC, file.ctime ASC
```

## 已出库灵感（按出库方向）

```dataview
TABLE 
  raw AS "原始闪念", 
  target_exit AS "出库方向",
  exit_status AS "出库状态",
  calibration_output AS "产出引用"
FROM "20-Cards"
WHERE type = "inspiration" AND status = "已出库"
SORT file.mtime DESC
```

## 灵感统计

```dataview
TABLE WITHOUT ID
  status AS "状态",
  length(rows) AS "数量"
FROM "20-Cards"
WHERE type = "inspiration"
GROUP BY status
SORT length(rows) DESC
```
