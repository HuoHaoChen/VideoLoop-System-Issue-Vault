# 🌐 世界观总览

## 已固化的世界观

```dataview
TABLE statement AS "一句话", domain AS "领域", method AS "方法"
FROM "20-Cards"
WHERE type = "worldview" AND status = "已固化"
SORT created DESC
```

## 验证中的世界观

```dataview
TABLE statement AS "一句话", domain AS "领域", method AS "方法"
FROM "20-Cards"
WHERE type = "worldview" AND status = "验证中"
SORT created DESC
```

## 草稿

```dataview
TABLE statement AS "一句话", domain AS "领域"
FROM "20-Cards"
WHERE type = "worldview" AND status = "草稿"

```

## 世界观引用热度

> 哪些世界观在系统中被引用最多（通过其他卡片的 worldview_ref 字段）

```dataview
TABLE length(rows) AS "被引用次数", rows.title AS "引用它的卡片"
FROM "20-Cards"
WHERE worldview_ref
GROUP BY worldview_ref
SORT length(rows) DESC
```

## ⚠️ 零引用世界观（定义了但没人用的世界模型）

```dataview
TABLE statement AS "一句话", domain AS "领域", status AS "状态"
FROM "20-Cards"
WHERE type = "worldview"
```
