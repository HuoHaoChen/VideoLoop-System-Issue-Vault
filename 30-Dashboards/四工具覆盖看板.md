# 四工具覆盖看板 (DSH / GPT / Codex / Hermes)

> V3.2 — 审计四个工具的问题投递覆盖。`source_tool` 缺失的新卡列在最下方（2026-08-26 起新卡必填）。

## 各工具投递统计

```dataview
TABLE length(rows) AS "卡片数"
FROM "20-Cards"
WHERE type = "problem" OR type = "change" OR type = "calibration"
GROUP BY source_tool
```

## 按工具分组明细

```dataview
TABLE type AS 类型, domain AS 领域, status AS 状态, severity AS 严重度, ke_ref AS "KEDB"
FROM "20-Cards"
WHERE type = "problem" OR type = "change" OR type = "calibration"
SORT source_tool ASC, created DESC
```

## 复发记录（命中 KEDB 的 P 卡）

```dataview
TABLE source_tool AS 来源, ke_ref AS "KEDB", status AS 状态
FROM "20-Cards"
WHERE type = "problem" AND ke_ref
SORT created DESC
```

## 缺 source_tool 的新卡（应补标）

```dataview
TABLE type AS 类型, created AS 创建日期, recorded_by AS 记录者
FROM "20-Cards"
WHERE (type = "problem" OR type = "change" OR type = "calibration")
  AND !source_tool AND created >= date(2026-08-26)
SORT created ASC
```
