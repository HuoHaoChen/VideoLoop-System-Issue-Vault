# 校准 & 过程看板
## 违规：未校准却已下结论（应为空）
```dataview
TABLE verdict, calibrated, calibration_ref
FROM "20-Cards"
WHERE type="change" AND verdict!="待校准" AND (calibrated!=true OR !calibration_ref)
```
## 违规：过程未留痕却要结案（应为空）
```dataview
TABLE type, status, verdict, process_captured
FROM "20-Cards"
WHERE (type="change" AND verdict!="待校准" AND process_captured!=true) OR (type="problem" AND status="已解决" AND process_captured!=true)
```
## 违规：记录者=评估者（应为空）
```dataview
TABLE recorded_by, evaluator
FROM "20-Cards"
WHERE type="change" AND recorded_by=evaluator
```
## 违规：软领域声称统计显著（应为空）
```dataview
TABLE domain, significance
FROM "20-Cards"
WHERE type="change" AND (domain="认知" OR domain="系统") AND significance="统计显著"
```
## 违规：运营决策借软域洞见却声称已验证（方向阀，应为空）
```dataview
TABLE domain, borrows_from, verdict
FROM "20-Cards"
WHERE type="change" AND domain="运营" AND (borrows_from="认知" OR borrows_from="系统") AND verdict!="待校准"
```
