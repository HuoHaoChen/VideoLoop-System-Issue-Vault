5|## 📋 卡片看板
6|
7|### 🟡 未处理 / 设计中
8|
9|```dataview
10|TABLE WITHOUT ID
11|  file.link AS "卡片",
12|  type AS "类型",
13|  domain AS "领域",
14|  due AS "截止"
15|FROM "20-Cards"
16|WHERE status = "未处理" OR status = "设计中"
17|SORT due ASC
18|```
19|
20|### 🔵 执行中 / 观察中
21|
22|```dataview
23|TABLE WITHOUT ID
24|  file.link AS "卡片",
25|  type AS "类型",
26|  domain AS "领域",
27|  due AS "截止"
28|FROM "20-Cards"
29|WHERE status = "执行中" OR status = "观察中"
30|SORT due ASC
31|```
32|
33|### 🟢 已解决 / 已结案
34|
35|```dataview
36|TABLE WITHOUT ID
37|  file.link AS "卡片",
38|  type AS "类型",
39|  domain AS "领域",
40|  verdict AS "结论"
41|FROM "20-Cards"
42|WHERE status = "已解决" OR status = "已结案"

44|LIMIT 10
