# VideoLoop 面板

---

## 📋 卡片看板

### 🟡 未处理 / 设计中

```dataview
TABLE WITHOUT ID
  file.link AS "卡片",
  type AS "类型",
  domain AS "领域",
  due AS "截止"
FROM "20-Cards"
WHERE status = "未处理" OR status = "设计中"
SORT due ASC
```

### 🔵 执行中 / 观察中

```dataview
TABLE WITHOUT ID
  file.link AS "卡片",
  type AS "类型",
  domain AS "领域",
  due AS "截止"
FROM "20-Cards"
WHERE status = "执行中" OR status = "观察中"
SORT due ASC
```

### 🟢 已解决 / 已结案

```dataview
TABLE WITHOUT ID
  file.link AS "卡片",
  type AS "类型",
  domain AS "领域",
  verdict AS "结论"
FROM "20-Cards"
WHERE status = "已解决" OR status = "已结案"
SORT created DESC
LIMIT 10
```

## 📅 截止日历

```dataview
CALENDAR due
FROM "20-Cards"
WHERE due
```

## 📊 三域统计

```dataview
TABLE length(rows) AS "数量"
FROM "20-Cards"
GROUP BY domain
```
