# 引用统计看板

## CAL 校准卡引用排行

```dataview
TABLE length(rows) AS 引用次数, rows.title AS 引用的修改卡
FROM "20-Cards"
WHERE type = "change" AND calibration_ref
GROUP BY calibration_ref
SORT length(rows) DESC
```

## P 问题卡关联排行

```dataview
TABLE length(rows) AS 关联修改卡数, rows.title AS 关联的修改卡
FROM "20-Cards"
WHERE type = "change" AND problems
FLATTEN problems
GROUP BY problems
SORT length(rows) DESC
```

## ⚠️ 零引用 CAL（建了但没人用的尺子）

```dataview
TABLE status AS 状态, created AS 创建日期
FROM "20-Cards"
WHERE type = "calibration"
```
