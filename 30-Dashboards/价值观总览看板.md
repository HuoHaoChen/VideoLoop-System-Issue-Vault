# 🏛️ 价值观总览

## 已固化的价值观

```dataview
TABLE statement AS "价值观声明", domain AS "领域"
FROM "20-Cards"
WHERE type = "values" AND status = "已固化"
SORT created DESC
```

## 验证中的价值观

```dataview
TABLE statement AS "价值观声明", domain AS "领域"
FROM "20-Cards"
WHERE type = "values" AND status = "验证中"
SORT created DESC
```

## 草稿

## 价值观引用热度

> 哪些价值观在系统中被引用最多（通过其他卡片的 value_ref 字段）

```dataview
TABLE length(rows) AS "被引用次数", rows.title AS "引用它的卡片"
FROM "20-Cards"
WHERE value_ref
GROUP BY value_ref
SORT length(rows) DESC
```

## ⚠️ 零引用价值观（声明了但没人用的信条）

```dataview
TABLE statement AS "价值观声明", domain AS "领域", status AS "状态"
FROM "20-Cards"
WHERE type = "values"
```
