# 待解决问题看板

> AI/智能体问题为主；工作域（运营）待确认。

```dataview
TABLE domain AS 领域, solution_status AS 解决状态, source_tool AS 来源, due AS 截止
FROM "20-Cards"
WHERE type = "problem" AND (solution_status = "待解决" OR (!solution_status AND (status = "未处理" OR status = "设计中" OR status = "执行中" OR status = "观察中")))
SORT domain ASC, created ASC
```
