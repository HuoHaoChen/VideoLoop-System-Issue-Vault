# 🚨 未归域告警

> 任何 domain="待分类" 且超过 7 天未归域的卡片，
> 违反三域平权原则，必须立即归域或归档。
> 当前 20-Cards/ 中无 domain="待分类" 卡片，看板暂时为空，
> 是预期状态。

## 🔴 严重（超过 14 天未归域）

```dataview
TABLE 
  type AS "类型",
  domain AS "domain",
  status AS "状态",
  (date(today) - file.cday).day + " 天" AS "搁置天数"
FROM "20-Cards"
WHERE domain = "待分类" 
  AND status != "已解决" 
  AND status != "已结案" 
  AND status != "归档"
  AND status != "降级归档"
  AND (date(today) - file.cday).day > 14
SORT file.cday ASC
```

## 🟡 警告（超过 7 天未归域）

```dataview
TABLE 
  type AS "类型",
  domain AS "domain",
  status AS "状态",
  (date(today) - file.cday).day + " 天" AS "搁置天数"
FROM "20-Cards"
WHERE domain = "待分类"
  AND status != "已解决" 
  AND status != "已结案" 
  AND status != "归档"
  AND status != "降级归档"
  AND (date(today) - file.cday).day > 7
  AND (date(today) - file.cday).day <= 14
SORT file.cday ASC
```

## 📊 待分类总数

```dataview
TABLE WITHOUT ID
  type AS "类型",
  length(rows) AS "未归域数量"
FROM "20-Cards"
WHERE domain = "待分类"
GROUP BY type
SORT length(rows) DESC
```
