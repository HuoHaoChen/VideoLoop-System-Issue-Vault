# 🔗 引用断链检测

> 自动检测 calibration_ref / problems / solution 字段
> 是否指向真实存在的卡片 ID。当前为预防性监控，
> "✅ 无断链"是预期状态。

## ❌ calibration_ref 断链

```dataviewjs
const ids = new Set(dv.pages('"20-Cards"').map(p => p.id).filter(Boolean));
const broken = dv.pages('"20-Cards"')
  .where(p => p.calibration_ref && String(p.calibration_ref).trim() !== "" 
              && !ids.has(p.calibration_ref));
if (broken.length === 0) {
  dv.paragraph("✅ 无断链");
} else {
  dv.table(["卡片", "断链 ID"],
    broken.map(p => [p.file.link, p.calibration_ref]));
}
```

## ❌ problems 断链

```dataviewjs
const ids = new Set(dv.pages('"20-Cards"').map(p => p.id).filter(Boolean));
const result = [];
for (const p of dv.pages('"20-Cards"')) {
  let probs = p.problems;
  // 容错：若 problems 是非空字符串，转为单元素数组
  if (typeof probs === 'string' && probs.trim()) {
    probs = [probs.trim()];
  }
  if (Array.isArray(probs)) {
    for (const pid of probs) {
      if (pid && !ids.has(pid)) {
        result.push([p.file.link, pid]);
      }
    }
  }
}
if (result.length === 0) {
  dv.paragraph("✅ 无断链");
} else {
  dv.table(["卡片", "断链 problem ID"], result);
}
```

const ids = new Set(dv.pages('"20-Cards"').map(p => p.id).filter(Boolean));
