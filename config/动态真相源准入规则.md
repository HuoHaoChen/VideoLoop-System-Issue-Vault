# 动态真相源准入规则

> 生效日期：2026-07-01（V3.0）

## 准入条件

| 条件 | 要求 |
|------|------|
| 信度等级 | S2 或 S3（S1 可临时观察，S0 不入） |
| 来源追踪 | 必须有来源卡片 ID |
| 过期条件 | 必须声明什么情况下退役 |
| 校验状态 | 必须通过 validate_loop.py |

## 退出条件

以下情况触发移除：

- 新证据证伪
- 适用场景变更导致不再有效
- 连续 3 次有效失败（降级或复测）
- 被更高信度判断替代

## 退役标记

退役的真相源不删除，进入「当前禁用判断.md」，标注退役原因和时间。

## 变更记录

每次增删改必须写入 `动态真相源变更日志.md`：

```plain text
日期 | 动作（新增/降级/退役） | 资产ID | 原因 | 操作人
```
