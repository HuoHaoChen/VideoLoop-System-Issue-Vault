# 50-TruthSource｜动态真相源

> 不是真理库，是经过 VideoLoop 校验后，当前阶段可暂时默认使用的判断索引。

## 核心规则

1. **只引用，不散写**：每条必须有来源卡片
2. **只收 S2/S3**：S1 可临时观察但标注，S0 不入
3. **每条必须有过期条件**：明确什么情况下这条判断应该退役
4. **变更是事件**：每次增删改都记入变更日志

## 文件结构

```
50-TruthSource/
├── README.md
├── 当前阶段默认判断.md       # S2/S3 判断资产索引
├── 当前禁用判断.md           # 已被证伪的判断
├── 当前高频失败反模式.md      # 活跃的失败反模式
├── 当前有效边界条件.md        # 已验证的边界条件
├── 临时观察-S1.md            # S1 方向信号（标注）
└── 动态真相源变更日志.md      # 每次变动的记录
```

## 判断资产升降级规则

| 档位 | 定义 | 允许说法 | 禁止说法 |
|------|------|----------|----------|
| S0 | 未经验证的假设 | 我假设 | 用户就是这样 |
| S1 | 单样本支持 | 有一条样本显示可能成立 | 这个方法已经有效 |
| S2 | 多样本方向稳定 | 在当前条件下有稳定信号 | 所有场景都有效 |
| S3 | 阶段默认判断资产 | 在这些边界条件下可作为默认 | 永久有效，不用复测 |
| Retired | 降级/淘汰/回炉 | 当前证据不支持，需复测 | 彻底无价值 |
